Access Dealer is a SaaS platform for **Privileged Access Management (PAM)** and **Cloud Infrastructure Entitlement Management (CIEM)**. A broker inside your network opens outbound mutual-TLS connections to Access Dealer, so SSH, RDP, database and Kubernetes access needs no VPN, public bastion or inbound firewall rule.

- **Just-in-time approvals**: approve exact targets, roles and durations in web, ChatOps or ITSM-backed flows.
- **Session recording**: live view, searchable transcript hits and a timeline tied to the approved request.
- **CIEM attack paths**: see identity-to-resource paths across cloud roles, policies and permissions.
- **Elevate**: temporary local admin for Linux, Windows and macOS after second-person approval.
- **MFA and policy**: mandatory MFA, ticket validation, approval rules and automatic expiry.
